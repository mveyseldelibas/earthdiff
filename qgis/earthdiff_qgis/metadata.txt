description=What changed here? Change detection from free Sentinel-2 imagery: vegetation loss and gain, new water, water loss, new bare soil / built-up, in hectares, with warnings.
about=Pick an area (map view, a drawn rectangle or selected polygons) and two dates. earthdiff compares free Sentinel-2 L2A imagery of the two periods and adds the change polygons, a class raster and true-colour before/after images to the map, plus an offline HTML report (swipe, scene by scene, 3D). Vegetation loss gets a likely-cause hint (fire-like / clearing-like / unclear). No account and no API key. A screening tool: it shows what changed, not why. Needs the earthdiff program in a normal Python installation (pip install earthdiff) or uv (uvx); the plugin finds it and runs it in the background. Data: contains modified Copernicus Sentinel data.
